# Telegram-бот для записи на сдачу лабораторных работ (aiogram 3)

Асинхронный Telegram-бот на базе **aiogram 3** и **aiosqlite**, предназначенный для организации электронной очереди студентов на сдачу лабораторных работ по парам.

---

## 🚀 Основные возможности

1. **Добавление пар (дата, время, предмет):**
   - **Автоматическая синхронизация расписания (текущая + следующая неделя):**
     - Загрузка из актуального ICS-календаря Самарского университета (`https://stud.l9labs.ru/ics/772107317.ics`).
     - Автоматическая фильтрация только лабораторных работ (лекции и практики игнорируются).
     - **Объединение сдвоенных пар:** если одна лабораторная идёт 2 пары подряд (например, 11:30–13:05 и 13:30–15:05), бот объединяет их в единый слот `11:30–15:05`.
     - **Разделение подгрупп:** если в одно и то же время у подгруппы 1 и подгруппы 2 идут разные лабораторные, создаются две отдельные лабораторные с независимыми очередями.
     - Сохранение ручных изменений: если администратор удалил автоматически созданную пару, повторный синк её не восстановит; вручную созданные пары никогда не затрагиваются.
     - Фоновое обновление каждые 6 часов, при старте бота и вручную по кнопке «🔄 Синхронизировать» или команде `/sync`.
   - **Ручное добавление:**
     - Удобный пошаговый диалог: название предмета, дата/время проведения, дополнительная информация (аудитория, преподаватель) и лимит мест.
     - Поддержка форматов даты: `15.09.2026 14:00`, `15.09 14:00`, `сегодня 16:30`, `завтра 10:00`, `15.09`.
   - Гибкие права доступа: создание пар доступно всем или только администраторам (настраивается в `.env`).
   - Возможность удаления пары создателем или администратором с подтверждением.

2. **Автоудаление прошедших пар:**
   - Пары автоматически удаляются/скрываются после завершения дня их проведения (когда наступает следующий день).
   - Фоновая периодическая очистка базы данных каждый час и при каждом старте бота.
   - Каскадное удаление записей очереди (`ON DELETE CASCADE`) при удалении пары.

3. **Очередь для каждой пары отдельная:**
   - Для каждого занятия формируется независимая нумерованная очередь.
   - Просмотр списка всех активных пар со счётчиком записавшихся: `(занято/всего)`.

4. **Запись в очередь:**
   - **⚡ Быстрая запись:** мгновенная запись на **первое свободное место** (наименьший свободный номер слота).
   - **🎯 Выбор любого свободного места:** интерактивная сетка слотов с индикацией занятых и свободных мест и постраничной навигацией.
   - Защита от коллизий: невозможно занять уже занятое место.
   - Один студент может занимать не более 1 места в рамках одной пары.
   - Возможность в любой момент **переместиться на другой свободный слот** или **покинуть очередь**.

5. **Профиль и имя пользователя:**
   - Каждый студент задаёт своё реальное имя и фамилию (ФИО), которое отображается в очереди для преподавателя и одногруппников.
   - Просмотр и изменение ФИО в любой момент через раздел «👤 Мой профиль».
   - При смене имени все текущие записи в очередях мгновенно обновляются.

## 🛠️ Стек технологий

- **Python 3.11+**
- **aiogram 3.31+** (современный асинхронный фреймворк для Telegram Bot API)
- **aiosqlite** (асинхронная работа с базой данных SQLite)
- **pydantic-settings** (типизированная конфигурация из `.env`)
- **pytest & pytest-asyncio** (автоматизированное тестирование)

## ⚙️ Установка и запуск

### 1. Клонирование и переход в директорию:
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd lab-register-bot
```

### 2. Создание виртуального окружения и установка зависимостей

С помощью **uv** (рекомендуется):
```bash
uv venv .venv
uv pip install -r requirements.txt
```

Либо со стандартным **python3 -m venv**:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Настройка конфигурации:
Скопируйте пример файла настроек:
```bash
cp .env.example .env
```
Откройте `.env` и укажите ваш токен от `@BotFather`:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
ADMIN_IDS=
DB_PATH=data/bot.db
ALLOW_ANYONE_CREATE_LESSONS=true
```

Параметры:
- `BOT_TOKEN`: токен Telegram-бота.
- `ADMIN_IDS`: Telegram ID администраторов через запятую (например, `123456789,987654321`).
- `ALLOW_ANYONE_CREATE_LESSONS`: если `true`, создавать пары могут все пользователи; если `false`, только указанные в `ADMIN_IDS`.
- `DB_PATH`: путь к файлу базы данных SQLite (папка создается автоматически).

### 4. Запуск бота:
```bash
source .venv/bin/activate
python -m src.main
```

## 🧪 Запуск тестов

Для запуска набора автоматизированных тестов выполните:
```bash
source .venv/bin/activate
pytest -v
```

Все 17 тестов проверяют:
- Корректность распознавания различных форматов дат;
- Изоляцию очередей между парами;
- Автоудаление пар по истечении дня и каскадное удаление их слотов;
- Атомарную запись на свободный слот и защиту от коллизий;
- Быструю запись на первое свободное место;
- Смену места в очереди и выход из неё;
- Обновление отображаемого имени студента во всех очередях;
- Генерацию клавиатур и постраничную навигацию.
